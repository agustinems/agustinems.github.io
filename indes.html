Política de Privacidad

Esta integración con Amazon Alexa fue creada para uso personal con el objetivo de controlar un servidor doméstico mediante Wake-on-LAN.

La aplicación no almacena, vende ni comparte información personal de los usuarios con terceros.

La información utilizada por la integración se limita únicamente a la necesaria para autenticar el acceso y ejecutar las funciones de control del dispositivo.

No se utilizan los datos obtenidos para publicidad, análisis comercial ni seguimiento de usuarios.
